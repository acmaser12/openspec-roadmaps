# Roadmaps

This directory contains structured plans for large efforts that span multiple reviewable OpenSpec changes.

Each roadmap lives in its own kebab-case directory and contains:

- `roadmap.md`
- `requirements.md`
- `phases.yaml`
- `decisions.md`

See `docs/roadmap-workflow.md` for the lifecycle and artifact rules. Roadmaps coordinate standard OpenSpec changes; OpenSpec does not apply or archive roadmap directories directly.
